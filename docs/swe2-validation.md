# SWE-2 有限模型验证

用户明确授权使用其称为免费的 swe2 做测试。实际调用模型：`openai-api-extension / devin/devin/swe-2`，API：官方 `pi-ai` 0.99.2 的 `openai-responses`。只读取该模型现有授权，运行时仅保留在内存；未加载第三方扩展、未改个人认证/模型配置、没有认证回退或换模。

## 输入与结果

仅用合成项目、无私人历史；磁盘写入在隔离目录。

总计 **4 次请求、2,131 tokens**，cacheRead/cacheWrite 为零；没有重试或 fallback。全部请求都经持久准入、输出限制与 90 秒取消信号；模型返回 usage，价格保持 `costUnknown=true`。模型 catalog 的零价格和用户所称免费不等于已核实账单。

输入估算采用 UTF-8 bytes 当保守 token 预留，本组分别预留 2061、795、1427、1315 input units，实际 input 491、232、368、337。没有预算跳过；这种小样本不能证明大型 Pi 快照不会被过度跳过，不能据此放宽或宣布默认预算最优。

## 证据与界限

历史验证入口：`test/swe2-validation.ts`，不会被 `npm test` 自动运行，须另获费用授权并显式 opt-in。这四次调用属于当时实施版本的观察；新增内容pending和协作接线之后没有重跑，不能据此保证当前自由正文会自动保存或当前模型质量已验。本次完整合成输入、生成 skill、模型输出和 request 账本回执：`/var/tmp/hermes-swe2-validation-V2QEGr/report.json`（无凭据）。永久保存的结果就是本页表格；临时目录不是未来唯一依据。

真实复用是在公共服务 seam 由宿主搜索/读取后向模型提供技能；未证明真实模型自主选择搜索工具。实际 Agent 的 registered-tool 搜索→读取→使用链路由 fake-provider SDK 测试覆盖，两种证据不能互相冒充。

未验证：长期效果、错误长期化概率、数万 token 上下文准入、cache 命中、所有 provider、跨插件及 TUI。任何扩展学习预算或调用轮数的方案仍须依照规格提出；不能把四个样例外推成保证。
